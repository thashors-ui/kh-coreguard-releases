# Security

- **Private keys:** release signing keys are kept offline by the owner and are never committed, uploaded or stored on
  GitHub.
- **No customer data:** this repository holds no customer data, no telemetry and no configuration of any installation.
- **Existing releases:** never modified. Each version gets a new tag. Only the `channel-<name>` pointer releases receive
  a newer signed manifest; installations refuse older ones.
- **Reporting:** contact the KH CoreGuard owner directly (not through public issues).
